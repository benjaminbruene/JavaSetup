# JavaSetup

**Name:** Benjamin

## Description
This project verifies that my Java development environment is set up correctly for the course. It uses the provided Main.java file and course setup library to test Java and several tools that will be used in future assignments.

## Development Environment
- IDE: IntelliJ IDEA 2026.2.1
- JDK: Java 21

## How to Run
1. Open the JavaSetup project in IntelliJ IDEA.
2. Open `src/Main.java`.
3. Run the `Main` class.
4. View the setup results in the Run console.

## Screenshot
A screenshot showing the program running successfully is included in this repository.

## Setup Issues
The course `.jar` file needed to be added as a project dependency in IntelliJ before running the program. After adding it through Project Structure, the program compiled and ran successfully.

The SQLite JDBC driver was not found, but the setup program states that this is expected if the instructor has not provided the JDBC driver yet.
